# StyleNest Frontend

StyleNest Frontend is a modern and responsive e-commerce web application built with React.js. It delivers a seamless online shopping experience with an intuitive user interface, efficient state management, product search and filtering, authentication, shopping cart functionality, and secure Razorpay payment integration.

## Features

- User registration and login
- JWT-based authentication
- Browse all products
- Product search by keyword
- Category-based filtering
- Product details page
- Shopping cart management
- Wishlist functionality
- Secure checkout with Razorpay
- User profile management
- Order history
- Pagination
- Responsive design
- Toast notifications
- Loading and error handling

## Tech Stack

- React.js
- Redux Toolkit
- React Router DOM
- Axios
- React Toastify
- CSS3
- Razorpay


## Key Functionalities

- Browse and search products
- Filter products by category
- View product details
- Add and remove items from the cart
- Secure checkout with Razorpay
- Manage user account
- View order history
- Responsive UI for all screen sizes
